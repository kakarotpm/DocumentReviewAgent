# New Invoicing System BRD

## Introduction

This document describes the requirements for the new invoicing system. The finance team has asked for a better way to handle invoices because the current process is not working well.

## Objectives

- Improve the invoicing process.
- Make things faster for the AP team.
- Increase user satisfaction.

## Scope

The project will deliver:

- Invoice scanning
- Automatic matching
- Approval workflow
- Reporting

## Stakeholders

Finance, IT, Procurement.

## Requirements

- The system should be fast and user-friendly.
- The system should use OCR to read invoices and store them in a PostgreSQL database.
- The system should match invoices to POs.
- Approvals should be easy.
- Reports should show all the important information, etc.
- The system must integrate with the ERP using a REST API with JSON payloads.

## Next Steps

The IT team will start building once this document is agreed.
